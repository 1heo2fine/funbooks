## Tech Stack
- HTML5/CSS3/JS for frontend (single-file implementation)
- Google Fonts (Nunito/Comic Neue) for typography
- Font Awesome for icons
- Client-side JavaScript for password validation
- Responsive design with media queries
- Placeholder emojis/gradients for game thumbnails
- No external dependencies (except Google Fonts)

## Library Rules
1. Use client-side JS only for password check (no server-side)
2. All game data stored in JS array (no databases)
3. Use relative URLs for game iframes
4. Avoid tracking/analytics libraries
5. Font Awesome only for icons, not layout
6. Google Fonts limited to specified families
7. Placeholder images must be self-contained (no external URLs)
8. Dark mode toggle implemented via CSS variables
9. All code must be well-commented for school use
10. No third-party libraries beyond specified ones
